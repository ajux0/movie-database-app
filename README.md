# Movie Database App

A responsive movie database application built with **React.js** that allows users to discover movies, search for movies, view movie details, and navigate through movie listings using pagination.

## Live Demo

https://movie-database-app-liart.vercel.app/

## GitHub Repository

https://github.com/ajux0/movie-database-app

## Features

- Browse popular movies
- Browse top-rated movies
- Browse upcoming movies
- Search for movies
- Movie pagination with Next and Previous buttons
- View movie details and cast
- Loading and error states
- Responsive design
- TMDB API integration

## Technologies Used

- React.js
- JavaScript
- React Router
- Styled Components
- REST API
- TMDB API
- Jest & React Testing Library
- Vercel

## Pages

- **Popular Movies:** `/`
- **Top Rated:** `/top-rated`
- **Upcoming:** `/upcoming`
- **Movie Details:** `/movie/:movieId`
- **Search:** `/search/:query`

```bash
git clone https://github.com/ajux0/movie-database-app.git
